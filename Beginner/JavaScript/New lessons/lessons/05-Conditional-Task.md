### Task 1: Traffic Lights

Your mission should you chose to accept it is to make a constant variable called "lightColour" and give it a value of "red", "orange" or "green". Then make an if statement block for what each colour means. Your If statement should also handle if "red", "orange" or "green" are not entered. This computer will now self destruct.

### Task 2: Temperature Check

For this task you are going to have a variable `temperature` you should create a if statement block to handle the following conditions:

- If `temperature` is greater than 30 - display "It's hot" in the console.
- If `temperature` is between 15 and 29 - display "its nice weather" in the console.
- if `temperature` is less than 15 - display "bring a jacket" in the console.

### Task 3: Quiz Check

For this task you are going to need to create 2 variables:
- `correctAnswers` which is equal to 8
- `totalQuestions` which is equal to 10

Then using what you learnt in the earlier tasks calculate the percentage of questions they got right and make an If statement to check:
