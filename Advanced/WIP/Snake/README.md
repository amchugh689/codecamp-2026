# Build Snake with Python & PyGame

## Overview

Over 4 short lessons, you will build a classic Snake game from scratch using Python and PyGame in the CodeHS Pygame sandbox.

You will end up with a snake you control on a grid, food that makes it grow, wall and self-collision that ends the game, and a score, plus a set of optional extensions to make the game your own.

This is self-guided prep for the end-of-week game competition. Nobody is marking this. Work at your own pace, experiment, and feel free to skip ahead if something feels too easy or slow down and re-read if something doesn't click.

Each lesson is split into two pages:
- A **concepts** page: the theory, explained on its own, with no code-along steps
- A **task** page: where you put that theory into practice by building the game

## Before You Start

You should already be comfortable with:
- Variables and basic maths operators
- `if` statements
- `for` and `while` loops
- Writing and calling functions
- Lists

No prior PyGame experience is needed; each lesson introduces what you need as you go.

## Setting Up

1. Log in to CodeHS and create a new **Pygame** sandbox (look for a Pygame template under the Python sandbox options)
2. All the code for this series goes in `main.py`
3. Use **one sandbox for the whole series**: each lesson adds to the code from the one before

## Tips

- Run your code after every change: it's much easier to spot what broke in 3 new lines than in 30.
- If something doesn't work, compare your code line-by-line against the lesson's complete code.
- Change numbers (cell size, move speed) and see what happens. Breaking things on purpose is a great way to learn.
