# 🐍 Build Snake with Python & PyGame

## Tutorial Series Overview

Welcome to the **Snake Game Tutorial Series**! Over 8 lessons, you will build the classic Snake game from scratch using Python and PyGame — all within the CodeHS online IDE.

By the end of this series, you will have a fully playable game with smooth movement, growing snake, random food, collision detection, a scoreboard, Game Over screen, and restart functionality.

---

## Who Is This For?

- High school students with basic Python knowledge
- You should already understand: **variables**, **loops**, **functions**, **lists**, and **conditionals**

## Setting Up CodeHS for PyGame

### Step 1: Log In to CodeHS

Go to [codehs.com](https://codehs.com) and log in with your school account.

### Step 2: Create a New Pygame Sandbox

1. Click **Sandbox** in the top navigation (or go to [codehs.com/sandbox](https://codehs.com/sandbox))
2. Scroll down to the **Python** section
3. Find the tile labelled **Pygame** — it says *"Use Python to create graphical games."*
4. Click **Create New**

### Step 3: Understand the Editor

You will see:
- **Left panel**: Your code editor with a file called `main.py`
- **Right panel**: The output area where your game will appear
- **Run button**: The green ▶ button at the top to run your program

### Important Notes

- **PyGame is already installed** — you do NOT need to install anything
- **All code goes in `main.py`** — unless a lesson says otherwise
- **Click Run (▶) to test** — your game window appears in the output panel
- **Click Stop (■) to end** — this closes the game window

### Recommended Approach

Use **one sandbox for the entire series**. Each lesson builds on the previous one, so you will replace and expand your code as you progress. This mirrors how real software development works.

If you want to keep a copy of each lesson's code, you can create a new sandbox for each lesson instead.

## Tips for Success

1. **Type the code yourself** — don't just copy-paste. You learn more by typing.
2. **Run your code after every change** — catch errors early.
3. **Read error messages carefully** — they tell you the line number and what went wrong.
4. **If stuck, compare your code to the lesson's complete code** — look for typos and missing colons.
5. **Experiment!** — Change numbers, colours, and speeds to see what happens.

## Getting Help

- **Syntax errors**: Check for missing colons (`:`), parentheses, and correct indentation
- **Game won't start**: Make sure you selected the **Pygame** sandbox type (not Python 3 or Python Turtle)
- **Black screen**: Your game loop might be missing — check Lesson 1
- **Ask your teacher**: They have teacher notes for each lesson
