## Conditional Statements — Tasks

---

### Task 1: Traffic Lights

Create a variable called `lightColour` and set it to `"red"`, `"orange"`, or `"green"`.

Write an if/else if/else block that:
- Logs `"Stop"` if the light is red
- Logs `"Get ready"` if the light is orange
- Logs `"Go"` if the light is green
- Logs `"Invalid colour"` if none of the above match

---

### Task 2: Temperature Check

Create a variable called `temperature`. Write an if statement that:

- If `temperature` is greater than 30 → log `"It's hot"`
- If `temperature` is between 15 and 30 → log `"Nice weather"`
- If `temperature` is less than 15 → log `"Bring a jacket"`

---

### Task 3: Quiz Score

Create two variables:
- `correctAnswers` = `8`
- `totalQuestions` = `10`

Calculate the percentage, then write an if statement that:
- 90% or above → log `"Excellent!"`
- 70–89% → log `"Good job!"`
- Below 70% → log `"Keep practicing!"`
