## Variables

### What Are Variables?

A **variable** is like a labelled box where you store a piece of data - a number, a word, or a list. You give it a name so you can use it later.

```js
let score = 10;
```

Here, we created a variable called `score` and stored the number `10` in it.

### Why Are Variables Useful?

Variables let your program **remember** things:

- Keep track of a score in a game
- Store a user's name after they type it in
- Hold the result of a calculation

- Count how many times a button is clicked

---

### Data Types

Variables can store different **types** of data:

- **Numbers** - whole numbers or decimals (used for maths).
- **Strings** - text, always wrapped in quotes.
- **Booleans** - either `true` or `false`.
- **Arrays** - a list of values in one variable.
- **Objects** - a group of related values stored together.

#### Why Does the Type Matter?

Different types behave differently. If you don't know what type you're working with, your code might break or produce unexpected results.

For example, adding two strings `"4" + "5"` gives `"45"` (they get joined together), not `9`.

---

### How Do You Create a Variable?

Use `let` or `const`, followed by a name and a value:

```js
let name = "Alex";
const pi = 3.14;
```

- Use `let` when the value might **change** later.
- Use `const` when the value should **stay the same**.

---

### Maths Operators

You can do maths with variables just like on a calculator:

| Operator | What it does   | Example  | Result |
| -------- | -------------- | -------- | ------ |
| `+`      | Addition       | `5 + 3`  | `8`    |
| `-`      | Subtraction    | `10 - 4` | `6`    |
| `*`      | Multiplication | `6 * 2`  | `12`   |
| `/`      | Division       | `12 / 3` | `4`    |
| `%`      | Remainder      | `10 % 3` | `1`    |
