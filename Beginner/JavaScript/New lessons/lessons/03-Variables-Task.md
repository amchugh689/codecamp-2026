## Variables - Tasks

We can use `console.log()` to display things in the browser's console. This is useful for checking that variables hold the values we expect. In this exercise, we'll use it to learn how variables work.

---

### Task 1: Hello There

On the first line of your JavaScript file, write:

```js
console.log("Hello There")
```

Then click the green **Run** button. You should see "Hello There" appear in the output window. Congratulations, you've just written code!

---

### Task 2: Make a Variable

Create a variable called `age` that stores your age. Since your age won't change while the program is running, use `const`:

```js
const age = 291;
```

(Replace 291 with your actual age... unless you really are an intergalactic hero.)

Now on your own, create another variable called `name` that stores your name. Remember, names are strings, so the value needs to be in quotes (`""`).

---

### Task 3: Logging a Variable

Now use `console.log` to display your variables:

```js
const name = "Rocky";
const age = 291;

console.log("Hi, my name is " + name + " and I am " + age + " Earth years old")
```

Hit Run. You should see your name and age printed inside the sentence. Try changing the variable values and running it again.

---

### Task 4: Let's Do Some Maths

1. Create a `const` variable called `pi` with a value of `3.14`.
2. Create a `const` variable called `diameter` with a value of `5`.
3. Create a `const` variable called `circumference` that calculates `pi * diameter`.
4. Use `console.log` to display the result.

**Hints:**
- The multiply symbol in JavaScript is `*`
- Your answer should be `15.7`
