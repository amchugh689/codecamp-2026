## Try It Now!!

In the document below, update the `<head>` element with both a page title and a favicon.

Place any images used inside the `images` folder which we have provided for you. Ensure your file path begins with `/images/<Name_of_your_image_file>`

The following site can be used to generate a favicon for your site: [https://favicon.io](https://favicon.io)

Refresh your browser and view the new changes to the tab title and icon.
