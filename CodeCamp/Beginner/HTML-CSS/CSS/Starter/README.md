# Starter Files

If a student's CodeHS sandbox resets or loses continuity between activities, use these files to get them back to the right starting point rather than redoing earlier lessons.

Each file (or folder, once an external stylesheet is introduced) is named after the activity it prepares a student for, and contains the expected *result* of the previous activity:

- `01 Inline CSS.html` — starting point for **Activity 01**, i.e. the finished HTML page from the end of the HTML section
- `02 Internal style sheets.html` — starting point for **Activity 02**, i.e. the result of Activity 01 (inline style on the heading)
- `03 Link External CSS File/` — starting point for **Activity 03**, i.e. the result of Activity 02 (internal style sheet for paragraphs), plus a second image to style
- `04 Syntax/` — starting point for **Activity 04**, i.e. the result of Activity 03 (external `styles.css` linked, images bordered)
- `05 Styling by ID/` — starting point for **Activity 05**, i.e. the result of Activity 04 (`h1` tag selector added)
- `06 Styling by Class/` — starting point for **Activity 06**, i.e. the result of Activity 05 (`#introParagraph` ID selector added)

From Activity 03 onwards each folder contains both `index.html` and `styles.css` — copy both files across together so the link between them stays intact.

**Note on images:** these files reference `images/favicon.ico`, `images/photo.jpg`, `images/photo2.jpg` as placeholder paths. No actual image files are included — either supply your own images at those paths, or have students swap in their own filenames.
