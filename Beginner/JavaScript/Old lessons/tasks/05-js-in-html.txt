In HTML, we can use the <button> tag to add an interactive button to our website. To add a function to this, we can add the name of the function to the onclick event:

        <button onclick="myFunction()">Click me</button>

We are able to send pop-up alerts to the user with the alert() function:

        myFunction() {
            alert("Hello!");
        }

2. Make this function take a parameter, and add this parameter to the alert.
