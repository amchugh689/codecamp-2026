In JavaScript, we can use loops to iterate through code.

a) For loops will continue to iterate until it reaches a limit:
 for(let i = 0; i < list.length; i++) {
    // code
 } 
    The check in the loop can be any value, but in this example it iterates through the length of a list.

b) ForEach loops will iterate through a list of values
    let number = [12, 25, 39, 82] // Initialises an array
    number.forEach(myFunction)

    function myFunction(item, index, arr) {
        arr[index] = item * 10 // Iterates through the array and multiplies each value by 10
    }

c) While loops will continue to perform an action until a parameter is false
    
    let check = true;
    while(check) {
        // code
    }
