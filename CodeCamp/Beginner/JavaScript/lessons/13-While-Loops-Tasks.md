## While Loops - Tasks

---

### Task 1: Countdown

Create a variable `countdown` set to `10`. Use a while loop to log the numbers from 10 down to 1, then log `"Liftoff!"` after the loop ends.

---

### Task 2: Double Until 100

Start with a variable `num` set to `1`. Use a while loop to keep doubling `num` (multiply by 2) and log the value each time. Stop when `num` exceeds 100.

---

### Task 3: Guess the Number

Create a variable `secretNumber` set to `7` and a variable `guess` set to `0`.

Use a while loop that keeps adding 1 to `guess` until it equals `secretNumber`. Log each guess, then log `"Got it!"` when the loop ends.
