## forEach - Tasks

---

### Task 1: Log Each Item

Create an array of 5 animals. Use `forEach` to log each one to the console.

---

### Task 2: Multiply Each Number

Create an array of numbers: `[2, 4, 6, 8, 10]`.

Use `forEach` to log each number multiplied by 3.

---

### Task 3: Numbered List

Create an array of your favourite foods. Use `forEach` with the index parameter to log them as a numbered list:

```
1. Pizza
2. Tacos
3. Ice cream
```

**Hint:** The index starts at 0, so you'll need to add 1 to it.
