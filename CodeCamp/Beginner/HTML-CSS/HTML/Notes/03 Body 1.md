In the examples below, we will begin to populate the <body> element of our web page.

We will begin populating with some common tags to begin displaying content!

### Heading Tags

This example show you how to add headings to your webpage.

To add headings, we use the `<h>` tag.
There are 6 different sizes for a heading and the size for a header is denoted by the `<h>` tag, along with the level of heading you would like. 

Note:
`<h1>` defines the most important heading
`<h6>` defines the least important heading

```html
<h1> Heading 1 </h1>
<h2> Heading 2 </h2>
<h3> Heading 3 </h3>
<h4> Heading 4 </h4>
<h5> Heading 5 </h5>
<h6> Heading 6 </h6>
```
