## Functions — Tasks

---

### Task 1: Name and Age

Create a function called `displayInfo` that takes two parameters: a name and an age.

It should log: `"Your name is [name] and you are [age] years old"`

---

### Task 2: Adding Two Numbers

Create a function called `add2Numbers` that takes two parameters (`num1` and `num2`) and **returns** their sum.

Call the function and log the result.

---

### Task 3: Circle Circumference

Create a function called `calculateCircumference` that takes one parameter (the diameter) and **returns** the circumference (pi × diameter, where pi = 3.14).

Call the function and log the result.
