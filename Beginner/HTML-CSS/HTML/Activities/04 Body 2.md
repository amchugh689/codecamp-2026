## Try It Now!!

### Paragraph Tags  
Let's now add some text to your webpage!

Within the `<body>` element of your HTML document, add a paragraph tag (`<p>`) along with some text under your new header tags!

Reload your site and view the new changes to your page!

---

### Links  
Let's now add a link to your webpage!

Within the `<body>` element of your HTML document, add an `<a>` tag along with some link text!  
You should note that the text you insert between the `<a>` tags will be what is displayed as clickable text!

---

### Images  
And finally, let's add an image to our page.

Within the `<body>` element of your HTML document, add an `<img>` tag along with some alt text!

Refresh your page and view the new changes!
