# Starter Files

If a student's CodeHS sandbox resets or loses continuity between activities, use these files to get them back to the right starting point rather than redoing earlier lessons.

Each file is named after the activity it prepares a student for, and contains the expected *result* of the previous activity:

- `02 Head.html` — starting point for **Activity 02 (Head)**, i.e. the result of Activity 01 (Structuring)
- `03 Body 1.html` — starting point for **Activity 03**, i.e. the result of Activity 02
- `04 Body 2.html` — starting point for **Activity 04**, i.e. the result of Activity 03
- `05 Divs.html` — starting point for **Activity 05**, i.e. the result of Activity 04
- `06 Freestyle.html` — starting point for **Activity 06**, i.e. the result of Activity 05

There's no starter for Activity 01 (Structuring) — building that structure from a blank file is the point of the activity.

**Note on images:** these files reference `images/favicon.ico`, `images/photo.jpg`, etc. as placeholder paths. No actual image files are included — either supply your own images at those paths, or have students swap in their own filenames.
