# Build a Flappy-Bird-Style Game with Python & PyGame

## Overview

Over 4 short lessons, you will build a side-scrolling flap-and-dodge game, inspired by Flappy Bird, using Python and PyGame on CodeHS.

You will end up with a bird that falls under gravity and flaps upward on a key press, a stream of scrolling pipes with gaps to fly through, collision detection, and a score that goes up each time you pass a pipe, plus a set of optional extensions to make the game your own.

This is self-guided prep for the end-of-week game competition. Nobody is marking this. Work at your own pace, experiment, and feel free to skip ahead if something feels too easy or slow down and re-read if something doesn't click.

Each lesson is split into two pages:
- A **concepts** page: the theory, explained on its own, with no code-along steps
- A **task** page: where you put that theory into practice by building the game

## Before You Start

You should already be comfortable with:
- Variables and basic maths operators
- `if` statements
- `for` and `while` loops
- Writing and calling functions
- Lists

No prior PyGame experience is needed; each lesson introduces what you need as you go.

## Getting Started

Your CodeHS course already has this series set up as **Notes** and **Exercise** items, one pair per lesson: a Notes item with the concepts, and an Exercise item with the Pygame environment already configured. You don't need to create a sandbox yourself.

1. Open each lesson's Notes item to read the concepts, then its Exercise item to do the task
2. All the code for each lesson goes in `main.py`
3. Each Exercise's starter code is empty for Lesson 1, then already includes your finished code from the lesson before it from Lesson 2 onward, so nothing needs to be copied across by hand

## Tips

- Run your code after every change: it's much easier to spot what broke in 3 new lines than in 30.
- If something doesn't work, compare your code line-by-line against that lesson's complete code, linked in the table above.
- Change numbers (gravity, flap strength, gap size) and see what happens. Breaking things on purpose is a great way to learn.
